# Source Notes

This skill was independently written for interactive, equation-by-equation paper tutoring.

- High-level inspiration: [paper-reading-skill](https://github.com/ddhh-gif/paper-reading-skill/blob/fa33b709d420ae874633e932547bf2b7eecb22a3/SKILL.md). The referenced file was checked on 2026-11-11; this link pins the inspected revision.
- The shared high-level ideas are to explain the mathematical or physical problem, define symbols and units, state assumptions, and connect derivations to reproducibility.
- This repository does not redistribute the referenced skill text. Its instructions were independently phrased around an interactive tutoring contract.
- The default output is a conversation: explain one core equation and necessary related expressions, then wait for the learner's response. Notes are optional and follow the user's current project conventions.
